## M13-repository-r1

This distribution reorganises the M13 review package for repository use. The manuscript and its submission documents remain separate. Scientific inputs, candidate ledgers, results, historical freezes and acquisition records retain their original bytes.

- One README and one complete manifest replace overlapping M11/M12/M13 entry points.
- Documentation is consolidated in English Markdown, with linked result tables, source attribution and file-level licence scope.
- The H11 protocol and implementation specification have separately identified reader editions. The specification corrects an omitted “Do not” in the prohibition on trusting truth or mutation labels. The historical freeze continues to identify the excluded original documents.
- Wine sensitivity validation uses explicit checks that remain active under Python optimisation. The comparison checks the complete four-arm, 144-candidate, 72-ranking and 432-group scope before reporting success.
- The top-level runner verifies the inventory and runs the retained projections, Car Evaluation reconstruction, original Wine transfer and exploratory sensitivity in a disposable copy.

[REVISION_PROVENANCE.json](REVISION_PROVENANCE.json) records the source archive digest, unchanged files and revised or replaced files. Historical execution receipts describe their original runs; current scripts have new digests in [MANIFEST.json](MANIFEST.json). This is a review-package revision, separate from the version of the original evaluated software.
